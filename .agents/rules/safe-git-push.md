## Safe Git Push (No Automatic Push)

- **NEVER push code to remote repositories (`git push origin ...`) without explicit user permission.**
- Do not run `git push` automatically at the end of turns or tasks.
- Keep all modifications, tests, and commits local until the user explicitly requests uploading/pushing (e.g. "ارفع التعديلات", "ارفع المشروع", "push to remote").
